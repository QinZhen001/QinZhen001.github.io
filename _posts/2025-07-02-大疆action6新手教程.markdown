# DJI Osmo Action 6 新手教程

这篇教程分成两部分：

- **只想马上开拍**：先看第 1、2 章，直接照着设置。
- **想弄懂参数**：再看第 3—6 章，了解 PRO、视角、防抖和曝光。

文中参数以大疆官方规格和当前固件为准。不同固件可能调整部分功能、菜单位置或参数上限。

---

## 1. 首次使用：3 分钟完成设置

**Action 6 只有首次激活需要连接手机。** 激活完成后，可以脱离手机独立拍摄、回放和调参。

### 首次上手清单

1. 装入电池和 microSD 卡；也可以先使用机身内置存储。
2. 手机安装 DJI Mimo，登录 DJI 账号并连接相机。
3. 按 App 提示完成激活，随后检查并升级固件。
4. 在相机内格式化存储卡，避免文件系统兼容问题。
5. 检查时间和时区，确保素材时间戳正确。
6. 打开 **PRO 高级模式**，解锁更多曝光和色彩设置。

### 账号绑定说明

- 换手机后，安装 DJI Mimo 并登录同一个 DJI 账号即可重新连接。
- 一台相机同一时间只能绑定一个 DJI 账号。转让设备前，应先在原账号中解绑。

## 2. 新手直接抄的 4 套参数

如果暂时不想研究参数，先从下面四套设置开始。

### 2.1 日常记录 / 步行 Vlog

| 项目 | 推荐设置 |
| --- | --- |
| 分辨率 / 帧率 | **4K/30fps**；需要更流畅或轻度慢放时用 4K/60fps |
| 增稳 | **RS**；走动较剧烈时切 RS+ |
| 视角 | **标准（畸变校正）**；想要更宽画面用日常广角 |
| 曝光 | 自动，ISO 上限设为户外 800、室内 1600 |
| 白平衡 | 光线稳定时固定；环境变化大时用自动 |
| 色彩 | 不后期选普通 10-bit；要调色选 D-Log M 10-bit |

### 2.2 骑行 / 跑步 / 户外运动

| 项目 | 推荐设置 |
| --- | --- |
| 分辨率 / 帧率 | **4K/60fps**；需要明显慢放时用 4K/120fps |
| 增稳 | 颠簸路面用 **RS+**；需要锁定水平线时用 HS |
| 视角 | **广角**；兼顾建筑观感时用日常广角 |
| 曝光 | 自动，ISO 上限 800 |
| 白平衡 | 户外可固定在约 5500K，避免画面忽冷忽暖 |
| 安装 | 磁吸快拆装好后再次检查锁定，重要场景加防丢绳 |

### 2.3 室内 / 城市夜景

| 项目 | 推荐设置 |
| --- | --- |
| 分辨率 / 帧率 | **4K/30fps**，进光压力通常小于 60fps |
| 模式 | 普通视频或超级夜景 |
| 光圈 | 自动；纯暗光优先 f/2.0 |
| ISO | 尽量控制在 1600 以内 |
| 增稳 | RS 或 RS+；相机固定时可关闭电子增稳 |
| 色彩 | 想省事用普通 10-bit，避免暗光 D-Log M 增加后期难度 |

### 2.4 慢动作

| 项目 | 推荐设置 |
| --- | --- |
| 分辨率 / 帧率 | **4K/120fps**；极限慢动作可用 1080p/240fps |
| 光线 | 高帧率更吃光，尽量在白天或充足灯光下使用 |
| 增稳 | RS 或 RS+ |
| 后期 | 放到 24/30fps 时间线中进行慢放 |

> 对大多数新手来说，**4K/30fps + RS + 标准视角 + 自动曝光 + 普通 10-bit** 就是一套可靠的起步设置。

## 3. PRO 高级模式要不要开

PRO（高级模式）是专业参数的总开关。打开后，可以设置手动曝光、光圈、白平衡和 D-Log M 等选项。

开启方法：

1. 进入拍摄取景界面。
2. 点击屏幕右侧的图像 / 音频参数按钮。
3. 点击参数面板右上角的 **PRO**。

建议长期保持 PRO 开启，但不代表所有参数都要手动设置。新手可以继续使用自动曝光，只限制 ISO 上限，并在光线稳定时锁定白平衡。

## 4. 视角怎么选

Action 6 提供三种主要视角。区别不只是画面宽窄，还包括边缘畸变和裁切程度。

| 视角 | 特点 | 适合场景 |
| --- | --- | --- |
| **标准（畸变校正）** | 画面最自然，直线不易弯曲，但会有一定裁切 | 自拍、人像、口播、桌面拍摄 |
| **日常广角** | 在视野和畸变之间取得平衡 | 旅行、街景、建筑、日常记录 |
| **广角** | 视野最宽，边缘拉伸最明显 | 骑行、滑雪、潜水、第一视角 |

记住一句话：**拍人优先标准，旅行优先日常广角，运动第一视角优先广角。**

入口通常位于录制规格页面右上角的「增稳｜视角」设置中。部分高分辨率或高帧率模式可能限制可选视角，以相机实际菜单为准。

---

## 5. 防抖四档怎么选

四种增稳模式不是简单的“越强越好”。增稳越激进，通常意味着裁切越多、视角越窄。

| 模式 | 主要作用 | 推荐场景 |
| --- | --- | --- |
| **RS（RockSteady）** | 兼顾防抖、视角和自然运动感 | 日常走路、Vlog、轻度骑行 |
| **RS+（RockSteady+）** | 增加裁切，优先抑制剧烈抖动 | 跑步、山地车、颠簸跟拍 |
| **HB（地平校正）** | 校正一定范围内的画面倾斜 | 车辆、船只、轻度侧倾场景 |
| **HS（地平线增稳）** | 相机大幅旋转时保持地平线水平 | 滑雪、摩托压弯、跳伞等 |

选择口诀：

- 日常拍摄：**RS**
- 剧烈颠簸：**RS+**
- 小幅倾斜需要扶正：**HB**
- 大幅旋转仍要水平：**HS**
- 三脚架或固定机位：可关闭增稳，保留更多画面

HS 的重点是“锁水平线”，不是所有场景下都比 RS+ 更稳。自拍和日常 Vlog 盲目使用 HS，反而会因为裁切增加而让画面变窄。

## 6. 曝光参数：新手只需要懂这些

### 6.1 光圈

光圈控制进光量。f 值越小，光圈越大，进入相机的光越多。

| 光圈 | 特点 | 适合场景 |
| --- | --- | --- |
| **f/2.0** | 进光量大，弱光更有优势 | 室内、夜景、光线不足 |
| **f/4.0** | 进光量少，可压制强光并产生星芒效果 | 强光、城市灯光、创意拍摄 |

Action 6 是超广角运动相机，本身景深较深。f/2.0 的主要价值是增加进光量，不要期待它产生相机大光圈镜头那样强烈的背景虚化。

### 6.2 星芒 F4

星芒 F4 会把光圈固定在 f/4.0，让路灯、车灯、霓虹灯和水面反光等点光源形成星芒。

**它是创意效果，不是夜景提亮模式。** f/4.0 的进光量明显少于 f/2.0。纯暗光环境想拍得更亮、更干净，应使用自动光圈或超级夜景。

### 6.3 ISO

ISO 越高，画面越亮，噪点也越明显。建议：

- 晴天户外：ISO 上限 800
- 室内和一般夜景：ISO 上限 1600
- 光线很差：优先增加环境光、降低帧率或使用超级夜景，不要只靠提高 ISO

这些数字不是绝对红线。如果必须先拍到画面，可以适当提高 ISO，再接受一定噪点。

### 6.4 快门与 180° 法则

追求自然运动模糊时，可以把快门设为帧率的约两倍：

| 帧率 | 参考快门 |
| --- | --- |
| 25fps | 1/50s |
| 30fps | 1/60s |
| 50fps | 1/100s |
| 60fps | 1/120s |
| 120fps | 1/240s |

这就是常说的 180° 快门法则，但它不是必须遵守的硬规则：

- **日常记录**：自动快门更省心。
- **追求电影感运动模糊**：固定快门，并在强光下配合 ND 滤镜。
- **高速运动或需要截图**：更快的快门反而有利于保留清晰瞬间。

### 6.5 普通 10-bit 还是 D-Log M

- **不准备后期**：使用普通 10-bit，可搭配机内胶片影调。
- **准备认真调色**：使用 D-Log M 10-bit，获得更大的后期空间。

D-Log M 素材直看发灰是正常现象，需要在 DJI Mimo 或剪辑软件中先做色彩还原。新手第一次拍摄不必强行使用 D-Log M。

### 6.6 8K 要不要开

8K 适合需要大幅裁切或高分辨率输出的少数场景，但文件更大、耗电和发热更明显，部分增稳、色彩或机内功能也可能受限。

**日常拍摄优先 4K/30fps 或 4K/60fps。** 先把构图、曝光和收音做好，比盲目使用 8K 更重要。

## 7. 常见场景设置

### 7.1 步行自拍 / 口播

- 4K/30fps 或 4K/60fps
- RS
- 标准（畸变校正）
- 自动光圈，ISO 上限 800/1600
- 普通 10-bit
- 风大时开启降风噪，重要口播建议使用外接麦克风

自拍时不要盲目使用 RS+ 或 HS，它们会增加裁切，让脸在画面中显得更近。

### 7.2 骑行

- 普通道路：4K/60fps + RS 或 RS+
- 山地颠簸：4K/60fps + RS+
- 摩托压弯、画面必须保持水平：HS
- 第一视角优先广角，城市街景可用日常广角
- 户外白平衡可固定在约 5500K
- 快拆底座务必确认锁紧，重要机位增加防丢措施

### 7.3 舞蹈 / 舞台

**固定机位：**

- 三脚架固定时可关闭电子增稳
- 常规拍摄用 4K/30fps + 1/60s
- 常规拍摄用 4K/60fps + 1/120s
- 需要慢放用 4K/60fps + 1/120s
- 标准视角，避免舞台和人体边缘变形
- 白平衡手动固定，避免灯光变化时色温来回漂移

在常见 50Hz 灯光环境中，如果出现频闪，可尝试 25fps + 1/50s 或 50fps + 1/100s。

**手持跟拍：**

- 4K/60fps
- RS+，倾斜较明显时可尝试 HB
- 标准视角
- 自动光圈，ISO 上限 1600

### 7.4 水下 / 海边

- 裸机防水深度和防水壳规格以官方说明为准
- 水下优先广角
- 建议固定白平衡，减轻画面蓝绿色偏色
- 下水前检查电池仓、接口仓和镜头保护盖是否锁紧
- 上岸后用清水冲洗，并擦干仓门和密封圈周围的水分

### 7.5 城市夜景星芒

- 选择星芒 F4
- 画面中安排明亮的路灯、车灯或招牌灯
- 尽量降低 ISO，并将相机放稳
- 如果只想获得更明亮的夜景，改用自动光圈或超级夜景

## 8. 手势、语音与快捷录制

| 方式 | 用途 |
| --- | --- |
| **手势控制** | 自拍时远距离启停录制或拍照，具体手势和生效条件以当前固件为准 |
| **语音控制** | 通过语音启停录制、拍照或关机，强风和嘈杂环境下识别率会下降 |
| **快捷录制** | 关机状态按下录制键，快速开机并开始拍摄 |
| **DJI Mimo 遥控** | 远程取景、调参和启停，适合固定机位 |

关键镜头优先使用物理按键或 DJI Mimo 遥控，不要完全依赖手势和语音。

## 9. 素材导出与后期

### 9.1 导出到手机

1. 打开手机 Wi-Fi、蓝牙和 DJI Mimo。
2. 连接相机并进入相册。
3. 勾选素材后下载到手机。
4. 导出时确认分辨率，避免误选 1080P 或 720P 后误以为原片不清晰。

如果原片是 4K，并且需要保留完整画质，导出时应选择 4K。

### 9.2 导出到电脑

可以使用 USB-C 连接相机，也可以取出 microSD 卡通过读卡器复制：

- USB-C 可以访问机身内置存储和存储卡。
- 读卡器通常传输更直接，但无法读取机身内置存储。
- 素材通常位于 `DCIM/DJI_001` 目录。

### 9.3 后期注意事项

- D-Log M 素材先还原到正常色彩，再进行风格化调色。
- 4K/120fps 素材可放到 24/30fps 时间线中制作慢动作。
- 同一条视频尽量统一白平衡、色彩空间和导出规格。
- 完成备份后再格式化存储卡，不要只保留手机中的压缩版本。

## 10. 配件与保养

**屏幕可以贴膜，镜头前不建议额外贴普通保护膜。** 额外玻璃可能带来眩光、鬼影和清晰度下降。原装镜头保护盖本身就是可更换的防护部件。

常用配件按优先级选择：

1. 备用电池和可靠的 microSD 卡
2. 磁吸快拆、胸带、头盔或车把支架
3. 外接麦克风
4. ND8/16/32 滤镜
5. 潜水防水壳

每次下水或长时间户外拍摄前，检查仓门、密封圈、镜头保护盖和快拆底座。海水使用后及时用清水冲洗。

## 11. 新手常见误区

| 误区 | 正确理解 |
| --- | --- |
| 每次拍摄都要连接手机 | 只有首次激活必须连接，之后可以独立使用 |
| 参数调不了就是机器有问题 | 先检查是否开启 PRO 高级模式，以及当前规格是否限制该功能 |
| 视角越广越好 | 自拍和人物优先标准视角，避免脸和四肢被拉伸 |
| 防抖档位越高越好 | RS+ 偏重抑制颠簸，HS 偏重锁定水平线，选择取决于场景 |
| 星芒 F4 能提亮夜景 | F4 是星芒效果模式；暗光画质优先时用自动光圈或超级夜景 |
| 弱光只要提高 ISO | 高 ISO 会增加噪点，应优先降低帧率、增加光线或使用夜景模式 |
| D-Log M 发灰说明画质差 | 发灰是正常的，需要后期还原；不后期就用普通 10-bit |
| 180° 法则必须一直遵守 | 它主要用于获得自然运动模糊，日常记录可以使用自动快门 |
| 拍摄 4K，导出后就一定是 4K | DJI Mimo 导出时仍要确认选择 4K |
| 8K 一定比 4K 更实用 | 8K 文件更大、限制更多，日常使用 4K 更均衡 |
